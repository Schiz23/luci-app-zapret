Добавляет в службы простое/минималистичное меню для управления Zapret/Zapret2 на OpenWRT 25+

Полноценная работоспособность тестировалась только на оригинальных [Zapret](https://github.com/bol-van/zapret) и [Zapret2](https://github.com/bol-van/zapret2), на других сборках возможны ошибки т.к. пути могут отличаться.

- Отображает текущую версию Zapret/Zapret2, а так же установленного бинарника.
- Ручное управление сервисом запуск/остановка/перезапуск/отключение/включение автозагрузки.
- Редактирование хостлистов, как стандартных так и по своему пути.
- Отображение текущих параметров nfqws.
